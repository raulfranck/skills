# In progress

Skills em beta. Ficam fora do plugin e do README principal até irem para uma área; não têm página de documentação e podem mudar ou sumir sem aviso.

Para experimentar uma delas, copie a pasta da skill para `~/.claude/skills/<skill>` e abra uma nova sessão. Uma skill que depende de subagentes só funciona dentro do plugin: mova-a para uma área e teste com `claude --plugin-dir .`.
